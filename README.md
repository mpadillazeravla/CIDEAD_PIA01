# PROGRAMACIÓN DE IA - Tarea online 1

## Descripción de la tarea
En esta actividad vamos a crear un repositorio y a crear una pequeña red de contactos para conseguir visibilidad dentro de la comunidad de IA y empezar a construir una red de contactos para estar al día de la novedades en este campo.

## Actividades realizadas
+ **GitHub** : Crearemos una cuenta y un repositorio junto con un sencillo programa en Python con un "Hola Mundo".\
+ **Comunidad IA** : En Twitter (X) crearemos una pequeña red creando una lista sobre IA con perfiles interesantes y buscaremos listas interesantes a las que seguir.
